# 📸 Our Photo Booth

A fun online photo booth with filters, customization, and a **Together mode** so you and your partner can take photos at the same time from different locations! 💑

## Features

- 📷 4-shot photo strip (like a real mall photo booth)
- 🎨 8 filters: Normal, B&W, Sepia, Vivid, Cool, Warm, Bright, Invert
- 🌈 Custom border colors
- 💬 Caption + date stamp
- 💑 **Together mode** — real-time connection with your partner

---

## How to Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g. `photobooth`)
2. Upload all files (`index.html`, `style.css`, `app.js`)
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch → `/ (root)` → Save
5. Your site will be live at:
   `https://YOUR_USERNAME.github.io/photobooth`

Share that link with your partner and you're good to go!

---

## How Together Mode Works

1. Both of you open the same URL
2. Click **Together** mode
3. One person clicks **Create Room** — share the 6-letter code
4. The other person enters the code and clicks **Join**
5. Once connected, click **Start Booth** — countdown syncs for both!
6. The strip shows your photos side by side 💕
